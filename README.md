# Scoreboard app

A simple red vs blue scoreboard because I can never find what I want online. And no I do not want to download an app on my phone.

# Features

- Ability to go fullscreen, however doesn't work on mobile for some older devices.
- Enter a name for the teams, and the name will appear above the score.
- Can swap the teams including the score.
- Easy reset to 0.

### Created Using

- React
- Typescript
- HTML
- CSS
